# Security

If you believe you have found a security issue, please **do not** open a public GitHub issue with exploit details.

Email **bagmert1996@gmail.com** with a description and steps to reproduce. We will respond as soon as we can.

You may also use [GitHub private vulnerability reporting](https://github.com/mertbag96/laravel-domain-migrator/security/advisories/new) if you prefer.
